# Forest ruins asset sources

Photographic PBR textures by **Rob Tuytel / Poly Haven**; HDR environment by **Andreas Mischok / Poly Haven**:

- Forest Ground 01: https://polyhaven.com/a/forrest_ground_01
- Mossy Rock: https://polyhaven.com/a/mossy_rock
- Bark Brown 02: https://polyhaven.com/a/bark_brown_02
- Pine Tree 01 twig atlas, **Rico Cilliers and Rob Tuytel**: https://polyhaven.com/a/pine_tree_01
- Forest Slope HDRI: https://polyhaven.com/a/forest_slope

All five assets are **CC0 1.0**, including redistribution in the APK:
https://polyhaven.com/license — https://creativecommons.org/publicdomain/zero/1.0/

`assets/sources.json` pins each downloaded source URL and SHA-256. Source JPEG
maps are 1K; OpenGL normal maps and AO/roughness/metalness channels stay linear.
Only albedo is sampled as sRGB. HDRI is prefiltered by Filament cmgen into a
256-pixel cubemap mip chain and diffuse spherical harmonics. Downloads happen
at build time; the installed app uses bundled assets entirely offline.

A single pine sprig is cropped from the diffuse/alpha atlas for crossed, alpha-masked canopy cards. The crop rectangle is pinned in the source manifest.

Architecture, terrain, branches, folded leaves, ferns, ivy and their placement
are generated by this project's C++ code. No third-party model packs are used.
